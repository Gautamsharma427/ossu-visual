# OSSU Visual Roadmap

A visual, interactive React/Vite presentation of the current OSSU Computer Science curriculum.

## Features
- Visual learning path for Intro, Core, Advanced and Final Project stages
- Current OSSU curriculum courses with duration, effort, prerequisites, provider, resource links, alternatives and discussion links where listed
- Search across courses, subjects, providers, prerequisites and topics
- Required / Advanced / Remaining / Completed filters
- Course detail drawer
- Local progress tracking with browser localStorage
- Roadmap / Courses / Progress views
- Responsive layout and light/dark theme toggle
- OSSU Extras section based on the repository's extra-course list

## Run

```bash
npm install
npm run dev
```

Then open the Vite URL shown in the terminal.

## Source

The curriculum data is mapped from the OSSU Computer Science repository:
https://github.com/ossu/computer-science

This project is a visual interface, not an official OSSU product.
